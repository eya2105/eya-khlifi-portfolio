# Eya Khlifi – Portfolio

This is a modern, interactive portfolio built with Next.js, showcasing my work in AI, cybersecurity, and network engineering. It features glassmorphism design, smooth animations, and a responsive layout.

## Live Demo

[https://eya-khlifi-portfolio-gknu.vercel.app](https://eya-khlifi-portfolio-gknu.vercel.app)

## Key Features

- Glassmorphism UI with animated backgrounds
- Interactive project cards with 3D tilt and smooth navigation
- Project detail pages with markdown rendering
- Dynamic glitter background and scroll progress indicator
- Responsive design across all devices
- Dark theme with professional color accents

## Tech Stack

- Next.js 16 with App Router
- Tailwind CSS
- Framer Motion for animations
- TypeScript
- gray-matter for markdown parsing
- lucide-react for icons

## Getting Started

### Prerequisites

- Node.js 18 or higher
- npm or yarn

### Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/eya2105/portfolio.git
cd portfolio
npm install
```

### Development

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

### Production Build

Build and start the production server:

```bash
npm run build
npm start
```
